# Passwordmanager

Ein einfacher Passwordmanager mit grafischer Benutzeroberfläche, entwickelt mit Python und CustomTkinter.

#Funktionen

1.Login Oberfläche
2.Benutzer Oberfläche mit Custom Tkinter
3.Zugangsdaten für Websites und Apps hinzufügen
4.Gespeicherte Einträge auflisten

#Programm Sprache

Pyhton

#Geplante Erweiterungen

1.Passwort-Generator mit konfigurierbarer Länge und Zeichenauswahl
2.Passwörter in die Zwischenablage kopieren
3.Zugangsdaten dauerhaft speichern und laden
4.Einträge bearbeiten und löschen
5.Suchfunktion für gespeicherte Zugangsdaten
6.Verschlüsselung der gespeicherten Passwörter
7.Verbesserung der Authentifizierung

#Projekt Status

Das Projekt befindet sich noch in der Entwicklung. Neue Funktionen/Verbesserungen werden schrittweiße hinzugefügt.
